この章では、専用ウィンドウの項目別に「できること」を解説します。

## 主な設定項目について

| 設定項目 | 説明 | 操作・補足ヒント |
| :--- | :--- | :--- |
| **ターゲット指定** | 変換したいアバターを選択します。 | メニューから開いた場合は自動で設定されます。<br />※空欄の場合はアバターをドラッグ＆ドロップしてください。 |
| **変換対象範囲**<br />*(複数可・任意)* | 指定したパーツのみをホログラム化します。<br />※未指定（空欄）の場合は**アバター全体**が対象。 | **特定パーツ（服や髪など）のみ変換したい場合:**<br />1. Hierarchyで対象を選択<br />2. **[Hierarchyで選択中のオブジェクトを追加]** をクリック<br />*( <kbd>Ctrl</kbd> + 左クリックで複数選択・一括追加可能 )* |
| **元のアバターを複製して変換** | チェックを入れると、元のアバターを残したまま複製して変換します。 | 元アバターを保護するため**チェック推奨（デフォルトON）** |
| **初期カラープリセット** | ホログラムの初期発色を選択します。 | `シアン` / `パープル` / `グリーン` / `レッド` / `オレンジ` / `カスタム` |
| └ **ベースカラー色相** | アバター本体の発光色を設定します。 | **[カスタム選択時のみ表示]**<br />数値（`0.0`〜`1.0`）で自由指定 |
| └ **輪郭カラー色相** | アバターの外周の発光色を設定します。 | 同上 |
| └ **スキャンライン色相** | 体に流れるの発光色を設定します。 | 同上 |
| **Expressionメニュー<br />自動生成** | チェックを入れることで変換時に自動でアバター直下に<br />専用メニューが組み込まれる。 | 基本はチェックありのままでOK |
| **保存先フォルダ** | 生成されたマテリアルが指定された所に保存されます。 | 基本はそのままにしてください。 |


<details>
  <summary>💡カスタム設定用：数値（色相）と色の対応目安</summary>

数値（スライダー）を動かす際の色相の目安です（`0.5` ＝ `50%`）。

| 数値（%表示） | 変化する色 |
| :---: | :--- |
| **`0.00` / `1.00`** (0% / 100%) | 赤 |
| **`0.08`** (約8%) | オレンジ |
| **`0.17`** (約17%) | 黄色 |
| **`0.33`** (約33%) | 緑 |
| **`0.50`** (50%) | シアン（水色） |
| **`0.67`** (約67%) | 青 |
| **`0.75`** (約75%) | 紫（パープル） |
| **`0.83`** (約83%) | マゼンタ / ピンク寄り |
| **`0.92`** (約92%) | ホットピンク寄り |
</details>

:::tip 変換対象範囲の便利な使い方
* **複数回に分けて追加可能:** 「1回目に耳と尻尾を追加」→「2回目にアクセサリーを追加」のように分割して登録・変換できます。
* **自動まとめ機能:** 複数回に分けて変換した場合でも、Expressionメニューや「通常外見に戻す」機能はすべての変換範囲を自動でまとめて処理してくれます。
:::

## ホログラム基本パラメータ

アバターの明るさや透明度、グリッチ（ノイズ）演出の細かな調整を行えます。

| 設定項目 | 説明 | 初期値・補足 |
| :--- | :--- | :--- |
| **全体の明るさ** | ホログラム全体の発光強度を調整します。 | 初期値: `0.4` |
| **基本の透明度** | アバターの透け感を調整します。 | 初期値: `0.2`<br />※`1`で完全不透明、`0`でほぼ透明。 |
| **頂点グリッチ有効化** | ホログラム特有のノイズ（画面のブレ）演出を有効化します。 | 初期値: **ON（チェックあり）** |
| └ **横ズレの強さ** | ノイズ発生時にメッシュが横にブレる大きさを調整します。 | 初期値: `0.006`<br />※「頂点グリッチ有効化」がONのときのみ機能します。 |

:::info 設定に迷ったら
まずは**初期値（デフォルト設定）のまま変換**してみるのがおすすめです。変換後でも見た目は簡単に微調整できます。
:::
